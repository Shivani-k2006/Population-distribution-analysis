# Population Distribution Analysis – Power BI

A Microsoft Power BI data visualization project that analyzes and presents the population distribution of selected countries using the World Bank **Population, Total (SP.POP.TOTL)** dataset for the year **2022**.

---

## 📌 Project Overview

This project demonstrates how Power BI can be used to transform raw population data into an interactive and visually meaningful dashboard.

The dashboard compares the population of selected countries using a **Clustered Bar Chart**, making it easy to identify differences in population size across countries.

---

## 🎯 Objectives

* Import and analyze World Bank population data
* Visualize categorical data using a horizontal bar chart
* Compare population across multiple countries
* Apply filtering and sorting in Power BI
* Create a clean and professional dashboard

## 📂 Dataset Information

**Dataset:** World Bank Open Data

**Indicator:** SP.POP.TOTL

**Name:** Population, Total

The dataset contains yearly population statistics for countries around the world. For this project, the visualization is filtered to **2022**.

---

## ⚙️ Steps Performed

1. Imported the World Bank population dataset into Power BI.
2. Cleaned and prepared the data.
3. Selected a Clustered Bar Chart visualization.
4. Added **Country Name** to the Y-axis.
5. Added **Population** to the X-axis.
6. Applied a visual filter for **Year = 2022**.
7. Sorted countries in descending order of population.
8. Formatted the chart with titles and labels.

---

## 📊 Key Insights

* India and China have the highest populations among the selected countries.
* The United States ranks third in population.
* Indonesia has a significantly larger population than the United Kingdom and UAE.
* The visualization clearly highlights population differences using a simple categorical comparison.
